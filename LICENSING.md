# Licensing

ccgram-hermes is MIT, not the 42labs default of AGPL-3.0 plus a commercial licence.

It is a plugin that runs inside ccgram's own process and exists only to extend it. ccgram is MIT, so
the plugin carries the same terms as the thing it plugs into. There is no commercial edition, so there
is no commercial half to protect and no contributor grant to ask for.

`LICENSE` holds the verbatim MIT text, with ccgram's copyright lines and 42labs' own, and nothing
else, so licence detection reads it correctly.
